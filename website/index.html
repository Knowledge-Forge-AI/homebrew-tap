Hikari, on distribution duty.

RS9’s admiral keeps a watchful eye on the supply lines.

This tap serves the organization’s projects. Release Starport 9 connects project releases to downstream distribution; Theme Forge Packages supplies the signed Linux repositories.

Exact formulas. Clear limits.

Formula source defines versions and installation behavior. The Theme Forge CLIs are qualified on Apple Silicon and Linux AMD64 / ARM64; Nebular is qualified on Apple Silicon. APGR declares all three targets, with Homebrew qualification still pending. Platform details and qualification evidence. Nebular is an ad-hoc-signed developer app, not a notarized Cask.

The tap currently contains the five formulas listed here. Other organization projects do not automatically have formulas. Terminal Nova themes are npm dependencies; follow their own installation guides.
